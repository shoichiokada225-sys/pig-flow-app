# ピッグフロー工程盤（pig-flow-app）

養豚場の豚舎レイアウトとロット（母豚グループ）の移動を、週次・日次で可視化する
**単一HTMLファイルの計画ボード**です。サーバー・ビルド不要。`index.html` をブラウザで開くだけで動きます。

## 主な機能

- **農場レイアウトマップ** — 交配舎・妊娠舎・分娩舎・離乳舎・肥育舎の区画をロット固有色で表示。移動日（月/火/水/金）は矢印アニメーションで流れを可視化
- **ロット追跡** — 部屋やガント行をクリックで1ロットをハイライト追跡。▶再生で日送りアニメーション
- **生産ラインビュー** — 各工程のWIP頭数・区画稼働率・ボトルネック表示、年間出荷頭数の試算
- **ロット別工程ガント**（週単位）と**日別ストリップ**（今週の作業予定）
- **飼養方式プリセット** — ウィークリー / 2-10 / 3-7 / 4-5 の各グループシステムに対応
- **Excel / CSV 読み込み・書き出し** — 区画数・収容頭数などの設定をCSVテンプレートで編集して反映（.xlsx / Shift-JIS CSV 自動判別）
- **PDF/印刷出力**（A4横）

## 日単位モデルの概要

ロットごとの経過日数 D（水曜離乳・交配舎入舎 = 0）で所在を決定します。

| D | 所在 | 移動 |
|---|------|------|
| 0〜32 | 交配舎（約35日） | 月曜に妊娠舎へ（D=33） |
| 33〜110 | 妊娠舎（約77日） | 火曜に分娩舎へ（D=111） |
| 111〜サイクル末 | 分娩舎（約28日） | 水曜に離乳→交配舎へ |

サイクルは哺乳3週=140日 / 4週=147日。部屋割りは入舎週 mod 部屋数のAIAOローテーション。
子豚は週次コホートとして離乳舎→肥育舎→出荷を頭数収容ビューで追跡します。

## データ保存

設定・頭数・メモはブラウザの `localStorage`（キー: `pigflow-board-v5`）に自動保存されます。
外部送信はありません。「例データに戻す（初期化）」ボタンでリセットできます。

## ファイル構成

```
index.html            アプリ本体（HTML/CSS/JS すべて含む）
vendor/               SheetJS（xlsx読み込み用・Excelインポート時のみ遅延ロード）
```

## 動作確認

自動テストはありません。変更時は `index.html` をブラウザで開き、
週送り・ロットクリック・CSV書き出し/読み込み・印刷プレビューを目視確認してください。
